## 1️⃣ Analytics Dashboard - For Administrators

### What It Does
The new Analytics Dashboard gives you comprehensive insights into how your team uses the Design & Pricing and Allocated Cost Calculator tools.

### How to Access It
1. Click on **Admin** in the sidebar
2. Select **Analytics**

### Dashboard Tabs

#### Overview Tab
See at-a-glance metrics:
- Total calculations across both tools
- Number of active users
- Month-to-month trends with growth percentages
- Visual charts showing usage patterns

**Example:** See that calculations increased by 23% last month compared to the previous month.

#### Design & Pricing Analytics
Track Design Tool usage:
- **Most Popular Routes:** Which route pairs are searched most (e.g., London ↔ New York)
- **Top Locations:** Both full location codes (IPCLON7) and city codes (IPCLON)
- **Bandwidth Trends:** Distribution across < 1 Gbps, 1-10 Gbps, 10-100 Gbps, 100+ Gbps
- **Top Customers:** Which customers are being quoted most often
- **Average Pricing:** Average suggested prices in USD
- **Response Times:** How fast calculations are running

#### Allocated Cost Calculator Analytics
Similar insights for the Allocated Cost Calculator, plus:
- **Quote Request IDs:** Track how many times specific quote IDs are searched
- Unique vs. repeated searches

#### User Analytics
Understand your team's usage:
- **Total Registered Users:** Current user count
- **User Registrations Over Time:** Growth trends by month
- **Daily Login Activity:** See login patterns over the last 30 days
- **Most Active Users:** Who's using the tools most, with breakdown by tool

#### Performance Tab
Monitor system performance:
- **Average Response Times:** Overall and daily trends
- **Calculations Per Day:** Usage patterns over 90 days
- **Peak Usage Times:** Best times by day of week and hour

### Date Filters
Every tab has date range options:
- Last 7 days
- Last 30 days
- Last 90 days
- Last year
- All time
- Custom date range

### Export Data
Each chart and table has an export button (download icon) - click it to download data as CSV for further analysis in Excel.

## 4️⃣ Cisco Routes - Now Included by Default

### What Changed
When you start a new design, "Include Cisco Only Routes" is now **checked by default**.

### Why This Matters
- More routing options available immediately
- Broader path diversity for your designs
- Better for exploring all possibilities

### Smart Auto-Toggle
When you enable "Protection Required," the system automatically:
1. Unchecks "Include Cisco Only Routes" (protection doesn't support Cisco routes)
2. Re-enables it when you turn off Protection Required

### Manual Control
You can still manually uncheck "Include Cisco Only Routes" if needed (when Protection Required is off).

## 5️⃣ Core Outages - Clearer Display

### Duration Display Improvements
Outage durations now show days, hours, and minutes:
- **Old:** 51h 30m (hard to visualize)
- **New:** 2d 3h 30m (instantly clear it's been 2+ days)

### Instant History Moves
**Before:** Outages stayed in "Current" tab for 24 hours after recovery  
**After:** Circuits move to history immediately when they recover

This means:
- "Current Outages" shows only circuits that are actually down right now
- No confusion about circuits that recovered hours ago
- Cleaner, more accurate dashboard

### Cleaner Interface
The statistics dashboard cards have been removed to focus on actual outage data.

## 7️⃣ Manual Incremental Costs - Allocated Cost Calculator

### What It Does
Add custom costs to your pricing calculations for scenarios not covered by standard circuit pricing.

### When to Use It
- Adding a completely new network segment
- Upgrading existing circuit bandwidth
- Including local loop costs at A-end or B-end
- Adding datacenter cross-connect fees

### How to Use It

#### Step 1: Expand the Section
Look for **"Manual Incremental Costs (Optional)"** accordion between Design Parameters and Route Results.

#### Step 2: Add a Cost
Click **"Add Incremental Cost"** button.

#### Step 3: Select Cost Type

**Core Incremental New**
- For completely new route segments
- Select source and destination from location dropdown
- Use for new network builds between locations

**Core Incremental Upgrade**
- For bandwidth upgrades on existing circuits
- Select which circuit you're upgrading
- Source/destination auto-filled from circuit

**Aggregate Cost A End**
- Additional costs at source location
- Example: Local loop from POP to customer premises
- Free-form text for source/destination

**Aggregate Cost B End**
- Additional costs at destination location
- Example: Cross-connect fees at destination datacenter
- Free-form text for source/destination

#### Step 4: Enter Details
- **Cost Amount:** The monthly cost
- **Currency:** Select currency (auto-converts to output currency)
- **Allocation Factor:** Percentage to apply (0.0 to 1.0)
  - Example: 0.5 = 50% of cost (for shared resources)
- **Path Allocation:** Primary or Secondary path

#### Step 5: Review in Results
Incremental costs appear in the detailed calculations table with:
- **Light green highlighting** for easy identification
- "New Core Circuit" label for new segments
- "CIRCUIT123 (Upgrade)" label for upgrades
- Allocation factor shown instead of utilization factor

### Path Validation
The system validates that existing circuits + new segments form a complete path from source to destination. You'll get a helpful error if the path is incomplete.

### Examples

**Example 1: New Core Circuit**
- Type: Core Incremental New
- Source: NYCNYC (New York)
- Destination: CHICHI (Chicago)
- Cost: 5000 USD
- Allocation Factor: 1.0
- Path: Primary

**Example 2: Circuit Upgrade**
- Type: Core Incremental Upgrade
- Circuit: LONLON123456
- Cost: 2000 USD (increase in monthly cost)
- Allocation Factor: 1.0
- Path: Primary

**Example 3: Local Loop**
- Type: Aggregate Cost A End
- Source: NYC POP
- Destination: Customer Premises NYC
- Cost: 500 USD
- Allocation Factor: 1.0
- Path: Primary

## 8️⃣ Customer-Owned Cross Connects

### What It Does
Mark locations where customers must provide their own cross connects (you can't supply them).

### Why It's Useful
- Track locations where you don't have cross connect provisioning rights
- Ensure sales team knows cross connect is needed but customer-provided
- No NRC/MRC charges appear in quotes

### For Administrators - Setting Up

#### Step 1: Open Location Manager
1. Go to **Data → Location Data**
2. Find the location
3. Click the cable icon to edit cross connects

#### Step 2: Enable Customer Owned
1. Check **"Customer Owned Cross Connect Only"**
2. Notice NRC and MRC fields grey out (showing "N/A - Customer Provided")
3. Add notes if needed (e.g., "Customer to arrange X/C with datacenter directly")
4. Click Save

**Important:** Only one can be enabled:
- **Enforce Mandatory Cross Connect** = You provide and charge for X/C
- **Customer Owned Cross Connect Only** = Customer provides X/C (no charge)

### For Users - Design Tool Display

When you select a location with customer-owned cross connect:

#### Automatic Display
- Cross connect automatically appears (cannot be removed)
- Header shows **(Customer Owned)** label
- NRC shows: **"Customer must provide X/C"**
- MRC shows: **"Customer must provide X/C"**

#### Example Display:
```
Source Cross Connect (Customer Owned)
POP Name: IPCLON7 - London Telehouse North
NRC: Customer must provide X/C
MRC: Customer must provide X/C
Notes: Customer to arrange X/C with datacenter directly
```

#### In Email Exports
- Shows "(Customer Owned)" label
- Displays "Customer must provide X/C" text
- No currency line (since there's no charge)

## ❓ Frequently Asked Questions

### Analytics Dashboard

**Q: Why don't I see the Analytics menu?**  
A: Analytics is only visible to users with Administrator role.

**Q: Can I see data from before this version?**  
A: Yes! Analytics shows all historical data since the system started tracking.

**Q: What does "N/A" mean in growth percentages?**  
A: When the previous month had zero calculations, growth percentage shows N/A (can't divide by zero).

### Pricing Logs

**Q: I'm a provisioner, why can't I see all logs?**  
A: Check your module permission level. You need "provisioner" level access to see all logs.

**Q: Can read-only users export logs?**  
A: Read-only users can only see and export their own logs.

### Allocated Cost Calculator

**Q: Where did the 60-month term go?**  
A: It was removed. Available terms are now 12, 24, and 36 months only.

**Q: Can I add multiple incremental costs?**  
A: Yes! Add as many as needed - each gets its own row in the table.

**Q: What if my path doesn't connect?**  
A: The system validates paths and shows an error if segments don't form a complete route from source to destination.

### Customer-Owned Cross Connects

**Q: Can a location have both mandatory and customer-owned enabled?**  
A: No - they're mutually exclusive. Only one can be enabled at a time.

**Q: What if I accidentally check the wrong one?**  
A: Just check the correct one - the system automatically unchecks the other.

**Q: Will this show in exports?**  
A: Yes - emails and exports show "(Customer Owned)" and "Customer must provide X/C" text.

### Carrier Contacts

**Q: What if I have a contact type not in the list?**  
A: Contact your administrator - they may add it to the system.

**Q: Can I leave Contact Level blank?**  
A: Yes - Contact Level is optional. Contact Type is required.

**Q: Will old contacts with different values still work?**  
A: Yes - existing data is preserved. The dropdowns only apply to new/edited contacts.
