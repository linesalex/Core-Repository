**Release Date:** November 28, 2024  
**Status:** 🧪 Testing

## 🎉 What's New in v3.4.1

### **Route Finder "View Map" Integration** 🗺️ - NEW FEATURE

Users can now visualize Route Finder results directly in the KMZ Map Viewer with a single click:
- **"View Map" button** next to Export Results in Route Finder
- **Primary path displayed in RED** for easy identification
- **Secondary/diverse path displayed in BLUE** for clear differentiation
- **Auto-zoom to source location** when map loads
- **Warning indicators** for any route segments without available KMZ files
- **Seamless navigation** - return to Route Finder without losing search results
- **Clean slate loading** - No auto-loading of Dark Fiber routes when viewing Route Finder results
- **Auto-cleanup** - Routes are cleared when navigating away from KMZ viewer

### **KMZ Map Viewer Regional Filtering** 🗺️ - PERFORMANCE OPTIMIZATION

The KMZ Map Viewer now supports regional filtering for bandwidth categories, significantly improving initial load times and reducing memory usage. Instead of loading all routes at once, users can selectively load routes by region.

## 📋 How to Use

### **Loading Routes by Region**

1. Navigate to **KMZ Route Viewer**
2. **Dark Fiber** section is expanded by default with EMEA pre-selected
3. Click on any bandwidth category accordion to expand it
4. **Parent checkbox** (e.g., "Dark Fiber") - Toggles ALL regions on/off
5. **Regional checkboxes** (EMEA, AMERs, APAC, INTER) - Toggle individual regions
6. Routes load automatically when a region is checked
7. Routes are removed when a region is unchecked

### **Understanding the Counts**
- Format: `Region (loaded/available)` - e.g., "EMEA (15/45)"
- **loaded** = Routes currently displayed on the map
- **available** = Total routes in database for that region

### **Parent Checkbox States**
- ☐ **Unchecked** - No regions selected
- ☑ **Checked** - All 4 regions selected
- ▣ **Indeterminate** - Some regions selected (1-3)

## 🔧 Technical Implementation

### **Backend API Updates**

**1. `/api/kmz_viewer/route_counts`**

Returns nested regional breakdown:
```json
{
  "dark_fiber": { "EMEA": 45, "AMERs": 50, "APAC": 35, "INTER": 15, "total": 145 },
  "gb_100": { "EMEA": 30, "AMERs": 40, "APAC": 25, "INTER": 10, "total": 105 },
  "gb_10": { "EMEA": 20, "AMERs": 25, "APAC": 15, "INTER": 5, "total": 65 },
  "lt_10gb": { "EMEA": 10, "AMERs": 15, "APAC": 8, "INTER": 3, "total": 36 }
}
```

SQL query uses `GROUP BY UPPER(region)` to aggregate counts.

**2. `/api/kmz_viewer/routes_by_bandwidth`**

New parameters:
- `filters` - Bandwidth category (e.g., `dark_fiber`, `100gb`)
- `regions` - Comma-separated regions (e.g., `EMEA,AMERs`)

Example request:
```
GET /api/kmz_viewer/routes_by_bandwidth?filters=dark_fiber&regions=EMEA,AMERs
```

Response includes `region` field for each route:
```json
{
  "dark_fiber": [
    { "circuit_id": "UCN-001", "location_a": "LON1", "location_b": "AMS1", "region": "EMEA", ... },
    { "circuit_id": "UCN-002", "location_a": "NYC1", "location_b": "CHI1", "region": "AMERs", ... }
  ]
}
```

### **Random Color Implementation**

```javascript
// 16-color palette for route differentiation
const PRESET_COLORS = [
  { name: 'Red', hex: '#FF0000', cesium: 'ff0000ff' },
  { name: 'Blue', hex: '#0066FF', cesium: 'ffff6600' },
  { name: 'Green', hex: '#00CC00', cesium: 'ff00cc00' },
  // ... 13 more colors
];

// Track last color to avoid consecutive repetition
const lastColorIndexRef = useRef(-1);

// Random color selection on route load
const getRandomColor = () => {
  let newIndex;
  do {
    newIndex = Math.floor(Math.random() * PRESET_COLORS.length);
  } while (newIndex === lastColorIndexRef.current && PRESET_COLORS.length > 1);
  lastColorIndexRef.current = newIndex;
  return PRESET_COLORS[newIndex];
};
```
