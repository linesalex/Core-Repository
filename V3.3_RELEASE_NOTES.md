## 🎉 What's New in v3.3.1

### **Enhanced Pricing Calculation Logs** - IMPROVED 📊

**Major Enhancement:**
All pricing calculations now include detailed, step-by-step mathematical breakdowns in audit logs!

**What's Included:**

#### 1. **Allocated Cost Breakdown**
- Per-segment calculations with circuit details
- Original cost and currency conversion
- Bandwidth utilization factors
- **Formula displayed:** `CustomerBandwidth / (SegmentBandwidth × UtilizationFactor)`
- **Calculation shown:** `SegmentCost × AllocationRatio = Result`
- Total allocated cost before/after rounding

#### 2. **Minimum Price Breakdown**
- Target margin percentage
- **Formula:** `AllocatedCost / (1 - Margin/100)`
- **Detailed calculation** with actual numbers
- Location minimum price comparison
- Final price formula: `MAX(PriceByMargin, LocationMinimum)`
- Indication if location minimum was enforced

#### 3. **Suggested Price Breakdown**
- Same detailed breakdown as minimum price
- Uses suggested margin percentage
- Shows all intermediate calculations

#### 4. **Protection Pricing Breakdown**
- Protection multiplier (70%) explanation
- **Allocated cost formula:** `Primary + (Secondary × 0.7)`
- **Minimum price formula:** `Primary Min + (Secondary Min × 0.7)`
- **Suggested price formula:** `Primary Suggested + (Secondary Suggested × 0.7)`
- Margin verification for protected service
- NRC charge explanation (charged once from primary)

#### 5. **Promo Pricing Breakdown** (when applicable)
- Original promo price and currency conversion
- Contract term discount application
- Margin requirement verification
- Full calculation steps

#### 6. **Margin Verification**
- Actual margin formulas displayed
- **Formula:** `((Price - AllocatedCost) / Price) × 100`
- Exact calculations for minimum and suggested margins

**Where to Find:**
- **Network Design & Pricing Tool** → Change Logs Viewer
- **Allocated Cost Calculator** → Pricing Logs tab
- Look for `detailedCalculationBreakdowns` in the pricing_data field

**Example Log Entry:**
```json
{
  "detailedCalculationBreakdowns": {
    "primaryPath": {
      "allocatedCostBreakdown": {
        "segments": [
          {
            "circuit": "CNX-001",
            "calculation": "1000 Mbps / (10000 Mbps × 0.9) = 0.111111",
            "allocatedCostCalculation": "5000.00 USD × 0.111111 = 555.56 USD"
          }
        ]
      },
      "minimumPriceBreakdown": {
        "calculation": "555.56 / (1 - 40/100) = 555.56 / 0.6000 = 926.00 USD"
      }
    }
  }
}
```

**Benefits:**
- ✅ Complete audit trail for pricing decisions
- ✅ Easy verification of calculations
- ✅ Training tool for new users
- ✅ Debugging complex pricing scenarios
- ✅ Compliance and accountability

**Updated Files:**
- `backend/routes.js` → Enhanced logging with detailed formulas
